## Piggy Meadow 
### A simple clock demo with pigs

---

#### Build from source code
Choose & run the script base on your platform
```bash
./build-[yourPlatform].sh
```
Find the result in dist/ directory

#### Enjoy the nature with the pigs
Click your mouse to summon new pigs
Some thing may happen if there are too may pigs...

#### Adjust the settings 
Some settings including the value of max_pigs are free to change with ./src/config.py
Build the program again with the script after changing the values
The author is not responsible for any damage caused by too many pigs :)
